# DSA Visualizer

An interactive, in-browser visualizer for core data structures and algorithms — built so you can *watch* how they work instead of just reading pseudocode. Made for juniors who are new to DSA and want to see it run step by step.

**Live demo:** [divyakukkal.github.io/DSA-VISUALIZER](https://divyakukkal.github.io/DSA-VISUALIZER/)

---

## What's inside

### Sorting
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

### Searching
- Linear Search
- Binary Search

### Data Structures
- Stack (push / pop)
- Queue (enqueue / dequeue)
- Linked List (insert head/tail, search, delete)

### Trees & Heaps
- Binary Search Tree (insert, search, delete, in/pre/post-order traversal)
- Min-Heap / Priority Queue (insert, extract-min)

### Graph Traversal
- BFS on a click-to-draw maze (guarantees shortest path)
- DFS on a click-to-draw maze

Every visualizer includes a speed control, and most include pause/resume, so you can slow things down enough to actually follow what's happening at each step.

---

## Tech stack

Pure **HTML, CSS, and vanilla JavaScript** — no frameworks, no build step, no dependencies. Open `index.html` in a browser and it just works.

---

## Run it locally

```bash
git clone https://github.com/divyakukkal/DSA-VISUALIZER.git
cd DSA-VISUALIZER
```

Then just open `index.html` in your browser — or, if you want live-reload while editing, serve it with any static server, e.g.:

```bash
npx serve .
```

---

## Why I built this

Reading pseudocode never made sorting or graph traversal click for me the way watching it actually run did. I built this to fix that for myself, and kept going once I realized it'd be genuinely useful for juniors who are just starting out with DSA — something they can click through and immediately see *why* an algorithm behaves the way it does, instead of just memorizing steps.
